Preguntas de comprensión:

1. ¿Qué ventaja tiene dibujar el diagrama UML antes de escribir el código?
   La ventaja de dibujar el diagrama UML antes de escribir el código es que así podemos identificar las relaciones entre clases, los errores que tengamos antes de crear el código, lo que ayuda a evitar perder tiempo en errores complejos.

2. ¿A qué parte del código corresponde cada una de las tres divisiones del diagrama de clases?
   en la parte superior ser encuentran el nombre de las clases.
   en la parte del centro están los atributos y variables.
   y en la parte inferior están los métodos.

3. ¿Cuál es la diferencia entre un comentario // y un bloque /** ... */ de Javadoc?
   la diferencia entre un comentario y un bloque en javadoc es que el comentario es como una nota de una sola línea que es dirigido a quien lo lee, mientras que un bloque es un comentario documentado, que busca explicar las clases o métodos.

4. ¿Por qué es importante documentar el código en un equipo de trabajo?
   es importante documentarlo para que cualquier integrante pueda entender el código sin necesidad de llamar al que lo escribió.
